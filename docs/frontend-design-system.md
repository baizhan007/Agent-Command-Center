# ACC 前端设计与维护说明

面向本地开发者的 Agent 工作台：中性深灰底色、薄荷绿主操作、蓝色运行状态与独立的成功色。总览优先展示失败任务和当前执行，协作树、已完成 DSH 记录与配置选项默认折叠，右侧展示本机 Agent 状态和会话摘要。

本轮使用 ui-ux-pro-max 的桌面 Web 布局、对比度、键盘交互和响应式检查规则。图标沿用现有 Lucide，不增加生产依赖。

## 代码入口

| 路径（相对 frontend/src） | 职责 |
| --- | --- |
| App.tsx | API、会话状态、业务表单和页面装配 |
| components/app-shell.tsx | 侧栏、顶部导航、语言和帮助 |
| components/overview.tsx | 按工作区聚合的总览 |
| components/workbench.tsx | 协作树、表格和空状态 |
| components/task-filters.tsx | 当前全局工作区内的搜索与状态筛选 |
| components/task-details.tsx | 任务详情、运行记录读取与重试、复制结果 |
| components/action-menu.tsx | Portal 更多菜单、定位与键盘操作 |
| components/dialog.tsx | Portal 弹窗、焦点约束和恢复 |
| hooks/use-navigation.ts | Hash 导航、前进后退和滚动位置 |
| lib/ | 类型、翻译、运行结果解析 |
| styles/ | 语义令牌、框架、工作台和弹窗样式 |

styles.css 统一加载样式模块；旧 desktop.css 已退出入口加载链。保留中英双语、桌面令牌注入和浏览器会话令牌，继续使用原有 /api 接口。

## 布局与交互

- 桌面使用左侧导航，内容最大宽度 1536 px；1050 px 以下总览转为单列主内容。
- 640 px 以下切换为四项底部导航，预留安全区域；主要按钮和图标操作采用至少 44 px 的触控高度。
- 表格在可聚焦容器内滚动。容器建立定位上下文，约束辅助文字的位置。
- 顶部提供跨页面唯一的全局工作区选择；侧栏项目快捷入口操作同一状态。总览、任务列表、项目列表与导航计数均采用该范围，设置页展示当前范围。移动端顶部也始终保留选择入口；引导流程仍可选择首次使用的工作区。
- 任务页保留搜索和细分状态筛选，提供全部、等待执行、运行中、失败、已完成快捷视图；统计卡片可跳转到对应视图。“等待执行”包含 pending / waiting / queued。列表按创建时间倒序展示，没有把创建时间伪装为活动时间。按 / 聚焦搜索，Escape 或清空按钮清除搜索词并保留其他筛选。
- 以“已完成的 DSH 任务”替代原验收队列，说明“暂未记录独立验收状态”，没有新增后端验收状态。已完成记录不会计入“需要处理”。
- Agent 状态显示本机进程信息，明确标注范围为全部工作区；它不表示当前工作区的连接或会话状态。
- 任务标题可直接打开详情，展示状态、创建时间、任务说明与运行结果。详情立即打开，运行记录单独加载；读取失败可重试，后台刷新失败保留旧结果并提示。关闭或切换详情会中止旧请求。Codex 主任务没有运行记录时仍可查看任务说明；关闭后恢复触发按钮焦点。详情标题与关闭按钮在滚动时保持可见，运行结果支持复制及失败反馈。
- 删除任务操作收进 Portal 更多菜单，避免表格滚动裁切；支持方向键打开、Escape 关闭和焦点恢复，点击外部、移出焦点、滚动或调整窗口时收起。删除前使用站内确认框显示目标名称，默认聚焦取消，提交时禁止重复操作；失败保留确认框供重试。
- 弹窗约束 Tab 焦点，支持 Escape，关闭后恢复触发控件焦点。提交期间禁用表单；失败后保留草稿并聚焦错误提示。
- 移除项目须确认，并说明关联任务记录会被移除，磁盘文件会保留。
- 排队、等待和运行中的任务禁止重复派发；停止操作仅对 ACC 拥有的 Codex 启动进程开放。
- 手动刷新提供忙碌状态，提示上次同步时间；设置保存时禁用相关选择器，成功后显示通知。新增、删除和刷新也提供短暂成功反馈；操作错误与连接错误分别维护，后台轮询不会清除尚未处理的操作错误。
