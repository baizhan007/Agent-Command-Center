ACC 安装与开发指南

一页完成本地运行、Windows 桌面安装和开发构建。点击右上角即可切换 English。

下载 Windows 桌面版

01 / 准备环境要求

  • Windows 11 与 PowerShell
  • Python 3.11
  • Node.js 20.19+、22.12+ 或 24+
  • Git for Windows

02 / 本地服务安装并运行 Web 控制台

在仓库根目录打开 PowerShell。安装依赖并生成本地配置：

Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
notepad .env

在 .env 中设置可信工作区父目录 ACC_ALLOWED_ROOTS，保存后启动服务：

.\start.ps1

访问 http://127.0.0.1:5173。停止服务： .\stop.ps1。

03 / Windows安装桌面应用

从 Releases 下载 ACC-Desktop-0.1.0-Setup.exe。启动后选择“简体中文”或“English”，按向导完成安装；安装程序默认安装到当前用户目录，也可选择安装路径。

便携版本：下载 ACC-Desktop-0.1.0.zip，解压后运行 Agent Command Center.exe。

当前安装程序未签名，Windows 可能显示安全提示。请确认文件来自本项目的 GitHub Releases。

04 / 开发运行测试与开发环境

安装依赖后，从仓库根目录运行后端测试与前端构建：

cd backend
.\.venv\Scripts\python.exe -m pytest
cd ..\frontend
npm run build

启动桌面开发环境：npm run desktop:dev（在 frontend 目录执行）。

从仓库根目录运行 .\build-desktop.ps1，生成 ZIP 便携版和中英双语 Windows 安装程序。

INSTALL · RUN · DEVELOP

ACC Setup & Development

Use this guide to run the local console, install the Windows desktop app, and build from source. Select 中文 above to switch languages.

Download for Windows

01 / PREREQUISITESRequirements

  • Windows 11 and PowerShell
  • Python 3.11
  • Node.js 20.19+, 22.12+, or 24+
  • Git for Windows

02 / LOCAL SERVICEInstall and run the web console

Open PowerShell in the repository root. Install dependencies and create the local configuration:

Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
notepad .env

Set ACC_ALLOWED_ROOTS in .env to trusted workspace parent directories, save the file, and start ACC:

.\start.ps1

Open http://127.0.0.1:5173. Stop the services with .\stop.ps1.

03 / WINDOWSInstall the desktop app

Download ACC-Desktop-0.1.0-Setup.exe from Releases. Choose 简体中文 or English in the installer and follow the wizard. It installs for the current user by default and lets you choose the destination folder.

Portable version: download ACC-Desktop-0.1.0.zip, extract it, and run Agent Command Center.exe.

The current installer is unsigned, so Windows may show a security warning. Verify that the file came from this project's GitHub Releases.

04 / DEVELOPMENTTest and build

After installing dependencies, run backend tests and build the frontend from the repository root:

cd backend
.\.venv\Scripts\python.exe -m pytest
cd ..\frontend
npm run build

Start the desktop development environment with npm run desktop:dev from the frontend directory.

Run .\build-desktop.ps1 from the repository root to create the portable ZIP and bilingual Windows installer.
